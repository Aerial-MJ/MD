# 熵崩塌（Entropy Collapse）：跨学科总览

> 关联笔记：GRPO/PPO 公式与 KL、entropy 正则项的推导见 [GRPO与PPO算法详解 · 七、KL 散度惩罚项详解](GRPO与PPO算法详解.md#七kl-散度惩罚项详解)；熵在 verl 训练日志中的实际表现（entropy / entropy_loss 曲线、超参排查表）见 [verl · 6.7 Entropy（熵）](../神经网络代码/verl.md#67-entropy熵) 与 [6.8 Entropy Loss（熵损失）](../神经网络代码/verl.md#68-entropy-loss熵损失)；PPO 正则项公式位置见 [MiniMind从0到1构建大模型 · KL、entropy 与 PPO 完整目标](../神经网络代码/MiniMind从0到1构建大模型.md#43-强化学习)。

熵崩塌是 RL 训练（尤其 GRPO/PPO 这类 on-policy RL for LLM）里最让人头疼的现象之一：策略的输出分布越来越"尖锐"，模型变得极度自信、几乎不再探索，token 级别的采样熵一路下降并"崩掉"，之后模型输出高度雷同、多样性消失，甚至性能不增反降。要理解它，我们从物理、化学、信息论、统计力学一路串到 SFT/GRPO，会发现这些领域讲的其实是同一个数学骨架在不同场景下的具现。

## 1. 物理学视角：熵与"退火"

### 1.1 玻尔兹曼熵与系统的微观状态数

物理学中最原始的熵定义（玻尔兹曼）：

$$
S = k_B \ln \Omega
$$

其中 $\Omega$ 是系统在给定宏观约束下可能的微观状态数。熵越大，代表系统可以"合法地待在"的状态越多，系统越"混乱"、越有多样性。

类比到语言模型：给定一个 prompt，模型在"下一个 token"这个位置上有一个概率分布 $p(\cdot \mid \text{context})$。这个分布覆盖的"有效候选 token 数"就类似 $\Omega$。如果分布非常尖锐（几乎只有一个 token 概率接近 1），相当于 $\Omega \to 1$，对应 $S \to 0$——这就是"熵崩塌"字面意义上的物理对应：系统坍缩到极少数几个微观态。

### 1.2 退火（Annealing）与"温度"

物理里的模拟退火：让系统从高温（高熵，粒子到处乱跑，容易跳出局部最优）逐渐降温（低熵，粒子逐渐固定到能量最低的构型）。降温太快 = "淬火"（quenching），系统来不及找到全局最优构型，就被冻结在某个亚稳态/缺陷态里出不来了——这在金属热处理里叫淬火脆化，材料内部应力没有释放，结构存在大量缺陷。

这几乎就是熵崩塌的物理原型：RL 训练如果奖励信号让某个（不一定最优的）输出模式过早地获得极高优势（advantage），策略会被迅速"淬火"到这个模式上，其余候选 token 的概率被指数级压低（softmax + 高置信度梯度的正反馈），熵断崖式下降，模型固化在一个次优解上，之后的探索能力（还能不能跳出去尝试别的解）几乎归零。

物理上对抗这个问题的手段——缓慢降温、加入随机扰动（模拟热噪声）——直接对应到 RL 里的做法：保持较高的采样温度、加熵正则（entropy bonus）、KL 惩罚控制策略偏移速度。这不是巧合，模拟退火算法本身就是从统计力学直接搬过来的优化算法。

### 1.3 相变（Phase Transition）视角

熵崩塌很多时候不是渐变的，而是类似一阶相变：训练曲线上熵会有一段时间缓慢下降，然后在某个临界点附近断崖式跳水（类似水结冰的潜热释放过程）。这是因为 softmax + 自举式的策略更新（模型自己生成数据、自己更新自己）存在正反馈机制：概率越高的 token 被采样得越多 → 获得的梯度更新越多 → 概率被推得更高 → 又被采样得更多。这是一个自增强的正反馈环路，一旦跨过某个临界点，就会发生类似相变的"雪崩"，而不是线性衰减。这也是为什么熵崩塌往往在训练日志里表现为"突然"发生，而不是能提前线性外推出来的。

## 2. 化学视角：反应平衡与耗散结构

### 2.1 化学平衡中的熵

化学反应的自发方向由吉布斯自由能决定：

$$
\Delta G = \Delta H - T \Delta S
$$

反应会朝着 $\Delta G < 0$ 的方向进行。当 $T\Delta S$（熵驱动项）相对于 $\Delta H$（焓驱动项）占主导时，体系倾向于往熵增（更混乱、更多构型）的方向走；反之低温下焓驱动占主导，体系会倾向于形成有序结构（比如结晶）。

类比：RL 训练本质上也在优化一个"自由能"式的目标——PPO/GRPO 的 loss 里，奖励项类似 $-\Delta H$（推动策略往高回报方向走，即"结晶"到某些好的输出模式），熵正则项类似 $T\Delta S$（鼓励维持多样性、抵抗坍缩）。如果去掉熵正则（相当于 $T \to 0$），系统就必然会"结晶"——也就是熵崩塌，策略被焓项（reward）单方面主导，一头扎进局部最优不可自拔。这正是为什么 GRPO/PPO 里熵系数（entropy coefficient）或 KL 系数是最关键的超参之一。

### 2.2 耗散结构与非平衡态

普利高津的耗散结构理论讲的是：一个开放系统在远离平衡态、有持续能量/信息输入的情况下，可以自发形成有序结构（比如台风眼、生物体），但这种有序是以不断消耗外部资源、产生更多熵输出到环境为代价的。

RL 训练某种意义上正是这样一个"远离平衡"的耗散系统：策略网络不断从环境（reward model / rule-based reward）获取"负熵流"（有效的梯度信号），维持自身在一个有序（高奖励）但非坍缩（保有探索）的非平衡稳态。一旦外部反馈信号（reward）质量变差或过于单一（比如 reward hacking、reward 稀疏/尖锐），系统会失去维持"活的、有序但不僵死"状态所需的负熵输入，最终坍缩到某个"死寂"的低熵吸引子——这正是熵崩塌的耗散结构语言版本。

## 3. 信息论视角：这是最贴近数学本质的一层

### 3.1 香农熵与不确定性

$$
H(p) = -\sum_i p_i \log p_i
$$

在语言模型里，$p$ 就是某一步的 next-token 分布。$H(p)$ 衡量的是模型对"下一个 token 该是什么"的不确定性/多样性。

- $H = 0$：模型 100% 确定输出某个 token（one-hot 分布）→ 完全确定性、零多样性；
- $H = \log|V|$（$V$ 是词表）：均匀分布，模型对下一个词毫无头绪，纯随机瞎猜。

训练健康的 RL 应该让熵缓慢、可控地下降（从"什么都不确定"逐渐收敛到"知道该怎么答但仍保留合理的不确定性"），而熵崩塌是这个下降过程失控加速，熵值过早跌到接近 0，此后模型对几乎所有 prompt 都用几乎相同的、高度确定的方式作答，哪怕这个答案是错的也不会再改变。

### 3.2 GRPO 里熵崩塌的信息论根因：似然位移（Likelihood Displacement）

这是最近（DeepSeek-Math、及后续一系列熵崩塌分析论文，例如 "The Entropy Mechanism of RL for LLM Reasoning"）给出的一个更精确的数学刻画。核心观察：

策略梯度更新在提升被采样到的"正确" token 概率的同时，会不成比例地压低其余 token 的概率，而且这个压低不是均匀的——协方差结构决定了压低幅度：

$$
\Delta H \approx -\eta \sum_a \text{Cov}\big(\log \pi(a \mid s),\ A(s, a)\big)
$$

也就是说，熵的变化量正比于"log 概率"和"优势函数（advantage）"之间的协方差。如果模型当前对某个高概率 token 恰好给了高 advantage（正反馈），这个协方差项就会很大，导致熵被大幅拉低。这解释了一个反直觉现象：**模型越自信的地方，熵崩塌的正反馈越强**——这就是为什么熵崩塌常发生在训练"看起来在稳定变好"的阶段，reward 曲线还在涨，但熵已经在加速崩塌，两者会在某个点交叉，之后 reward 也开始下滑（因为多样性没了，没法探索出更好的解，且泛化能力随之丧失）。

### 3.3 KL 散度：约束"跑得多远"

$$
D_{KL}(\pi_\theta \| \pi_{ref}) = \sum_i \pi_\theta(i) \log \frac{\pi_\theta(i)}{\pi_{ref}(i)}
$$

PPO/GRPO 里加 KL 惩罚，本质上是给策略更新加了一个"不能离参考模型（通常是 SFT 后的模型）太远"的约束，物理上类似前面说的"退火速率限制"——不让系统降温（收敛）太快。训练脚本中调的惩罚系数、以及 verl 配置里的 KL 系数，都是在直接控制这个"降温速率"。

## 4. 回到 SFT 和 GRPO：为什么两者的"熵故事"完全不同

### 4.1 SFT：本质是在做"最大似然 + 交叉熵最小化"

SFT 的 loss 是：

$$
\mathcal{L}_{SFT} = -\sum_t \log \pi_\theta(y_t^* \mid y_{<t}^*, x)
$$

这是纯监督学习，只有"标准答案"这一条轨迹会被强化，其余所有 token 都不会被显式压低（虽然 softmax 归一化会隐式压低，但没有 RL 里那种自举正反馈）。SFT 的"熵下降"是被动的、温和的：模型逐渐学会"标准答案长什么样"，熵随训练自然降低，但不存在协方差正反馈机制，所以一般不会出现断崖式的"熵崩塌"，而是稳定收敛。

这也正是"SFT 已经很根深蒂固了，很难让同一个样本产生多个不同回答"这一问题的根源：SFT 训出来的模型本身熵就已经偏低（对每个 prompt 高度确定该怎么答），拿这样的模型去做 GRPO 的第一步——采样 group（比如 4 条 rollout）——这 4 条 rollout 天生就长得很像，group 内部方差小，advantage 信号弱且噪声大，这会进一步加速稍后 RL 阶段的熵崩塌（因为一旦某条 rollout 因为噪声偶然获得略高 reward，模型会把仅有的那点多样性全部"焓化"到这条路径上）。

### 4.2 GRPO：奖励驱动的"自举式"更新，天生自带崩塌风险

GRPO 的更新用的是组内相对优势：

$$
A_i = \frac{r_i - \text{mean}(r_1, \dots, r_G)}{\text{std}(r_1, \dots, r_G)}
$$

问题在于：

- 没有 value function/critic 校准（这是 GRPO 相对 PPO 省资源的地方），advantage 完全依赖组内的相对排名，如果组内样本本来就同质化严重（前面说的 SFT 遗留问题），少数几个 token 的差异就会被放大成"决定性信号"，梯度对这些 token 极度敏感；
- rule-based reward（例如规则打分脚本）往往是分段的、有"陡坡"的（比如命中即满分、重罚项一旦触发就大幅扣分）。这种奖励地形本身就是"高对比度"的，会加剧协方差项 $\text{Cov}(\log \pi, A)$ 的幅度，是熵崩塌的直接助燃剂。把重罚机制从"乘法叠加"改成"取最重一项生效"是正确的调整方向——本质上就是在给奖励地形"削峰"，减少陡坡，从而减缓熵崩塌的正反馈强度；
- GRPO 通常没有独立的 critic 网络吸收方差，噪声更容易直接传导到策略梯度上，加速前面说的正反馈环路。

### 4.3 可以下手的"控熵旋钮"，对应到前面每个学科的原理

| 手段 | 物理/化学类比 | 对应训练脚本里的位置 |
|------|--------------|---------------------|
| 熵正则系数（entropy bonus） | 维持体系"温度"，防止骤冷 | verl 配置里的 `entropy_coeff`（如果开了的话） |
| KL 惩罚系数 | 限制"降温速率"，防止淬火 | `actor.kl_loss_coef` 之类的配置 |
| 奖励地形削峰（取最重一项而非叠乘） | 减少化学反应中的"陡峭势垒"，让体系平缓过渡而非剧烈放热 | `reward_fn_v2.py` 的重罚逻辑 |
| 弱提示做退火/最终去除 | 逐步撤除外部"负熵源"，让系统自身学会维持多样性而不是依赖外部输入 | 训练后期退火掉弱提示 |
| group size 增大 / 采样温度提高 | 增加初始"分子热运动"幅度，防止一开始就困在浅坑里 | rollout 时的 `temperature`、`n`（group size） |
| 数据配比多样化（A/B/C/D 四类数据源） | 增加系统"可及构型"的多样性，避免体系过早陷入单一吸引子 | 补充 D 类数据源 |

## 5. 一个统一的直觉收尾

如果把这几个学科的语言全部叠在一起看，其实讲的是同一件事：

任何一个通过"正反馈强化已发生事件"来学习/演化的系统（无论是热力学系统降温结晶、化学反应体系走向平衡、还是 RL 策略梯度自我强化），都存在从"多样、高熵、有探索能力"坍缩到"单一、低熵、丧失探索能力"的固有风险。抵御这种坍缩，靠的都是同一种机制——引入某种形式的"温度"或"噪声"，让系统的更新速度慢于它想要坍缩的速度。

对 GRPO 训练来说，最值得关注的实操信号是：看训练日志里的 policy entropy 曲线和 reward 曲线的相对走势——如果发现 entropy 下降斜率突然变陡（尤其是先于或伴随 reward 增长停滞/开始下降），这就是熵崩塌正在发生的强信号，此时应该检查 KL 系数是否太松、奖励地形是否太陡峭（比如某个重罚项过强导致 group 内 reward 方差被少数样本主导），而不是简单调大学习率或增加训练步数——这两者在熵崩塌语境下反而是"火上浇油"，会加速正反馈环路的收敛速度。
